# Mini-chat direct Kevin ↔ chaque personne dans CMCteams et la light (Kevin 5.11.2026, absolue, gratuit)
- « Dans CMC Teams, je veux la possibilité d'envoyer un message à une personne qui s'affichera sur son application quand elle l'ouvre à la prochaine connexion, et qu'elle puisse me répondre… un mini chat direct avec moi et seulement avec moi de chaque personne… un petit historique qu'on peut vider… toutes les fonctionnalités d'un chat… en cliquant sur une personne dans le planning… Toujours gratuit. »
- Le travail est fait par le DOMAINE : `services/kdmc-router/mini-chat.js` (routes `/__dm/…`, tables D1 `dm` et `dm_fil` de CERCLE_DB). Les pages ne vérifient rien : `tools/shared/mini-chat.js` (copie identique `tools/departs/mini-chat.js`) demande « qui es-tu ? » à `/__dm/badge`.
- Qui voit quoi : Kevin (admin prouvé) lit et écrit à n'importe qui (`/__dm/admin/*`) ; une personne ne voit QUE son fil avec Kevin, clé = son nom de session prouvée (code ou Face ID) trié sans accents, jamais le matricule ; un nom seulement déclaré n'ouvre rien (401 `code_requis`) ; POST seulement depuis `*.kd-mc.com`.
- Livraison : le message attend dans le fil ; à l'ouverture de l'app la fenêtre s'ouvre toute seule (une fois par nouveau message), les messages passent « Lu ✓✓ », la personne répond dans le même écran. Pas de push vers la personne ; Kevin reçoit un push (`outils.notifier`).
- Chat complet : bulles par jour, Envoyé ✓ / Lu ✓✓, 5 réactions (👍 ❤️ 😂 🙏 👀), « Retirer » son message, « Vider mon historique » (vide SA vue seulement), 500 caractères avec compteur, 40 messages/jour/personne, historique de 150 messages.
- Côté Kevin : CMCteams → fiche d'une personne → « 💬 Écrire » ; carte « 💬 Messages directs » en tête de l'accueil ; light → bouton « 💬 Messages » (liste des fils + recherche d'une personne). Côté personne : carte « Kevin t'a écrit (n) » / bouton « 💬 Kevin ».
- Gratuit (règle `quotas-gratuits.md`) : une lecture toutes les 5 min au plus, page visible seulement ; 30 s fenêtre ouverte ; jamais de balayage de table, `LIMIT` partout ; aucun cron.
- Limite connue : si le nom de la session d'une personne n'a pas les mêmes mots que son nom du planning, les deux fils ne se rejoignent pas ; Kevin le voit (« pas encore de compte connu » sous le fil).
- Nouvelle app qui veut le mini-chat : charger le script + `kdmcMiniChat.regler({personnes: q => […]})` ; jamais une 2ᵉ messagerie.
- Gardes : `npm run test:mini-chat` (46 contrôles du routeur, sabotage `SABOTAGE=cle|prouve|admin`) et `npm run test:mini-chat-ecran` (28 contrôles, vrai Chromium 375 px, `SABOTAGE=1` rouge). Après la mise en ligne, le déploiement du routeur vérifie `/__dm/` fermé aux inconnus.
