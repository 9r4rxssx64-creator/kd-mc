# Arbre : IA gratuites au travail, confidentialité d'abord (Kevin 26.11.2026, absolue, branches arbre)
- « Trouve des solutions pour garder la confidentialité au maximum et envoie un maximum d'IA gratuite au travail… les infos de tout le monde, en privé ou en public selon les mineurs. »
- Circuit : navigateur du Lenovo (Chromium neuf, `capteur.mjs`) → texte/image de la page publique → IA qui LIT (`tools/arbre/lecteur-ia.mjs`) → preuve mot pour mot → rapprochement local → rapport au pont → arbre-cloud écrit (`ecrire.sh`).
- OmniRoute (`npm install -g omniroute`, `omniroute`, http://localhost:20128/v1, modèle `auto`) = les IA gratuites du nuage ; un modèle LOCAL (Ollama, http://localhost:11434/v1) = rien ne sort du Lenovo. Voies : `tools/delegue/omniroute.mjs` ; sonde réelle : `node -e "import('./tools/delegue/omniroute.mjs').then(m=>m.sonde()).then(console.log)"`.
- Niveaux (`tools/arbre/confidentialite.mjs`) : OUVERT = défunt dont l'état civil est public (naissance ≥ 75 ans et décès ≥ 25 ans, ou naissance ≥ 100 ans) → local puis OmniRoute ; FERMÉ = vivant, mineur, récent, ou date inconnue → modèle LOCAL SEULEMENT (si absent : « en attente », jamais le nuage).
- L'IA ne connaît JAMAIS la cible : elle liste toutes les personnes de la page ; le rapprochement (nom + prénom + année/lieu) est fait en code. Garde de sortie : aucun nom de fiche fermée, secret, e-mail, téléphone ne part vers le nuage.
- Résultat : mineur → tiroir PRIVÉ ; vivant → privé/admin ; défunt → public. Jamais adresse, téléphone, e-mail, réseau social. Rien n'est écrit sans nom ET lieu/date concordants ; « piste » = « À retrouver », jamais un fait.
- Lots : `node tools/arbre/lots-ia.mjs --n 30 < export.json` (ouverts d'abord pour le nuage ; fermés marqués `local_seulement`). Robots génériques toujours suspendus (§7) ; aucun compte créé, aucun formulaire envoyé par un robot (Kevin le fait, un clic). Garde : `npm run test:arbre-confidentialite`.
