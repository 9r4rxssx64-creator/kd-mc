Staging — où tester quoi

Il n'existe qu'UN seul environnement de test : « staging ». Il n'y a pas de « dev ».

💬 Ouvrir Apex Chat de test

  • Page et serveur de test, base séparée de la production (bandeau « STAGING » visible).
  • Inscription avec un numéro de test et le code 000000 (ce code ne marche que là).
  • Pas de SMS, pas de notification, pas de connexion par le domaine.
  • Remise à zéro : le robot « staging-apex-chat-donnees » (action reset).

Cette page (staging.kd-mc.com) est la porte d'entrée du test, réservée à l'admin. Elle ne contient pas d'application elle-même.

  • Les autres apps (Arbre, Lingua, Bee, boutiques…) n'ont pas encore de version de test : on les essaie sur leur adresse habituelle, en lecture seule.
  • Les vraies apps restent sur leurs adresses habituelles.
