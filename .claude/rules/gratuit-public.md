# Les robots passent par le dépôt PUBLIC (Kevin 16.10.2026)

« Privilégie toujours le public. Enfin, en tout cas, toujours le gratuit. »
- Dépôt public `kd-mc` : minutes Actions gratuites et illimitées → c'est LUI qui déploie à chaque fusion (il récupère les fichiers du coffre en lecture seule).
- Coffre privé `CMCteams` (2 000 min/mois) : un push n'y lance pas le déploiement ; bouton manuel = secours seulement.
- Nouveau robot : public d'abord (ou le Lenovo, `KDMC_RUNNER`) ; un journal public n'affiche jamais un contenu privé.
- Garde : `npm run test:robots-public`.
